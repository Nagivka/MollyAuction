# 🏷️ MollyAuction

> **Современный, оптимизированный и многофункциональный плагин аукциона для серверов Minecraft (Paper / Purpur 1.21+)**

Автор: **nagivka**  
Версия: **1.2**  
Поддерживаемые версии: **Paper / Purpur 1.21+** (Java 21)

---

## ✨ Основные возможности

- 🔄 **Автоматическая миграция:** Автоматический перенос всех данных и настроек из старого плагина `NGVKauction` в `MollyAuction` при первом запуске без потерь.
- ⚡ **Soft Real-Time Refresh:** «Бесшовное» авто-обновление открытого меню аукциона в реальном времени без сброса курсора и звуков закрытия.
- 📦 **Покупка предметов по частям:** Игроки могут выкупать стаки частями через удобный интерфейс с ползунком/кнопками шага (+1, +8, +16, +32, максимум).
- ⏳ **Продление срока действия лотов:** Возможность продлевать время лота прямо из меню «Мои товары» с настраиваемой комиссией.
- 📥 **Хранилище просроченных предметов с кнопкой «Забрать всё»:** Быстрый возврат невыкупленных товаров в инвентарь одним кликом.
- 💰 **Гибкая экономика и комиссии:**
  - Поддержка **Vault** и **PlayerPoints**.
  - Налог на продажу (процент).
  - Фиксированная комиссия за сам факт выставления лота.
- 🔔 **Сводка продаж при входе:** Оповещение игрока о заработанных средствах и проданных товарах за время его отсутствия на сервере.
- 📜 **История транзакций:** Полноценное меню со списком всех ваших покупок и продаж (`/ah history`).
- 🛡️ **Модерация лотов для Администраторов:** Возможность снять любой подозрительный лот с аукциона прямо из меню по клику **Shift + ПКМ**.
- 🚫 **Расширенный черный список:** Блокировка предметов по Material, Display Name (подстроки), Lore (подстроки) и CustomModelData.
- 🎨 **Кастомизация и поддержка ресурс-паков:**
  - Интеграция с **Oraxen**, **ItemsAdder**, **Nexo**.
  - Поддержка **MiniMessage**, **HEX** цветов и **PlaceholderAPI**.
- 🗄️ **Высокопроизводительные базы данных:** SQLite (WAL-режим с защитой от lock-конфликтов) и MySQL.

## 📋 Команды

| Команда | Описание | Право |
|---|---|---|
| `/ah` | Открыть главное меню аукциона | `mollyauction.use` |
| `/ah sell <цена>` | Выставить предмет из руки на аукцион | `mollyauction.sell` |
| `/ah search <запрос>` | Поиск предметов по названию или описанию | `mollyauction.use` |
| `/ah my` | Открыть меню управления своими лотами | `mollyauction.use` |
| `/ah storage` | Открыть хранилище истекших/снятых предметов | `mollyauction.use` |
| `/ah history` | Посмотреть историю своих покупок и продаж | `mollyauction.use` |
| `/ah reload` | Перезагрузить конфигурацию плагина | `mollyauction.admin` |

---

## 🔐 Права (Permissions)

- `mollyauction.use` — Доступ к просмотру аукциона (по умолчанию есть у всех).
- `mollyauction.sell` — Доступ к выставлению предметов на аукцион.
- `mollyauction.limit.<кол-во>` — Лимит активных лотов для игрока (например, `mollyauction.limit.10`).
- `mollyauction.admin` — Полные права администратора (модерация через Shift+ПКМ, перезагрузка плагина).
- *(Также сохранена полная обратная совместимость с правами `ngvkauctions.*`)*

## 🛠️ Сборка из исходников

Для сборки требуется **JDK 21**:

```bash
# Клонирование репозитория
git clone https://github.com/Nagivka/MollyAuction.git

# Сборка проекта
./gradlew clean build
```

Скомпилированный `.jar` файл будет находиться в директории `build/libs/MollyAuction-1.2.jar`.
